드론방제 현장을 위한 기능

관리자는 전체 현황을 보고, 팀장은 작업자를 배정하고, 팀원은 오늘 해야 할 필지만 빠르게 처리합니다.

1

필지 지도 관리

필지 위치와 경계를 지도에서 확인하고 농가별 작업 대상을 빠르게 찾습니다.

2

지역별 목록

읍면/리 단위로 필지를 묶어 작업자가 이동 동선을 쉽게 잡을 수 있습니다.

3

팀별 작업 배정

팀과 작업자 기준으로 필지를 나누고 진행률을 확인합니다.

4

방제 알림

방제 시작과 완료 시 농가에 알림톡 또는 문자로 진행 상황을 안내합니다.

5

증빙 사진 관리

완료 사진을 촬영하거나 선택해 필지별 증빙 자료로 보관합니다.

6

현황 대시보드

오늘 작업, 팀 진행률, 증빙 미첨부 등 확인할 항목만 간결하게 보여줍니다.

역할별로 다른 화면

현장 앱은 모든 사람이 같은 화면을 볼 필요가 없습니다. 초해크롭은 관리자, 팀장, 팀원에게 필요한 기능을 나눠 제공합니다.

관리자

전체 운영 관리

  • 방제팀 생성과 초대코드 관리
  • 필지 등록, 삭제, 대량 업로드
  • 전체 작업 현황과 알림 확인
팀장

팀 작업 배정

  • 팀원별 작업 배정
  • 팀원 진행률과 증빙 확인
  • 팀원 색상과 작업 구분 관리
팀원

현장 작업 처리

  • 내 작업 목록 확인
  • 방제 시작/완료 처리
  • 완료 사진 촬영과 증빙 등록

방제 업무 흐름

필지 등록부터 작업 배정, 방제 완료, 증빙 확인까지 현장 흐름에 맞춰 동작합니다.

필지 등록

엑셀 대량 업로드 또는 개별 등록으로 농가와 필지를 정리합니다.

작업 배정

지역과 팀 기준으로 작업자를 배정하고 오늘 작업을 확인합니다.

현장 방제

지도와 목록에서 필지를 찾고 시작/완료 상태를 빠르게 기록합니다.

증빙 확인

완료 사진과 알림 발송 이력을 기준으로 작업을 마감합니다.

운영에 필요한 기본 신뢰

앱 심사와 실제 운영에 필요한 개인정보 처리방침, 서비스약관, 문의 채널을 공식 도메인에서 제공합니다.
